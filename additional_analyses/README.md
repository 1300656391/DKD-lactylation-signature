# Additional exploratory analyses

One-off sensitivity and exploratory analyses referenced in the manuscript
that are not part of the 14-step `pipeline/`. Each sub-folder holds the
analysis script together with its frozen output table.

| Folder | Manuscript item | Script | Frozen output |
|---|---|---|---|
| `single_vs_signature_S10/` | Table S10 - single-gene versus signature AUCs with DeLong tests | `18_single_vs_signature.R` | `TableS10_single_vs_signature.csv` |
| `control_sensitivity_S11/` | Table S11 - GSE104948 control-source sensitivity (living-donor / hypertensive-nephropathy controls) | `19_ld_sensitivity.R` | `TableS11_control_sensitivity.csv` |
| `disease_arbitration_S15a/` | Table S15a - disease arbitration, proxy correlations, PDK2-PDK4 asymmetry (10,000-resample dependent-correlation bootstrap + Steiger z) | `24_disease_arbitration.R` | `TableS15a_disease_arbitration.csv` |
| `cytokine_podocyte_S15b/` | Table S15b - cytokine-axis and podocyte-module correlations | `26c_s15b_complete.R` | `TableS15b_cytokine_podocyte_module.csv` |
| `gse273763_immune_nnls_S17/` | Table S17 - GSE273763 ssGSEA (two normalizations) and NNLS B-cell fractions | `step1_immune_gse273763.R`, `step1b_immune_nnls_gate.py`, `step1c_s17_corr_full.py` | `TableS17_gse273763_immune.csv` + intermediate CSVs |
| `gse273763_delong/` | GSE273763 DeLong comparisons (PDK2/PDK4 versus signature) | `46_gse273763_score.py`, `47_gse273763_nnls.py`, `48_gse273763_s17.py` | `verify_report_gse273763.txt` |
| `head_to_head_bootstrap/` | Head-to-head paired bootstrap (signature versus PTGS2, B = 2000) | `head_to_head.py`, `49_head_to_head.py` | `signature_vs_PTGS2_bootstrap.csv` |
| `2x_myeloid_ref/` | NNLS reference rebuild (section 2.7 sensitivity): combined GSE131882 kidney + GSE209781 disease-derived immune reference | `step1_annotate.R`, `step2_build_ref.R` | `ref_marker_list_combined.csv`, `ref_type_counts_combined.csv` |
| `2_cross_deconv/` | Reference-constrained NNLS deconvolution re-run on the bulk cohorts (section 2.7 cross-method sensitivity; B-cell fraction proxy) | `step1_extract.R`, `step2_deconv.py`, `step3_secondary.py` | `deconv_fractions_all.csv`, `deconv_group_tests.csv`, `deconv_pdk_correlations.csv` |

The scripts keep the original `evidence_gain/...` workspace paths they were
written in; rerunning them requires reconstructing that layout (GEO inputs
per `pipeline/README.md`; annotated single-cell objects regenerated by
`pipeline` step 10 and by `2x_myeloid_ref/step1_annotate.R` from the
GSE209781 RAW archive). The per-cohort `bulk_*_subset/pheno.csv` extracts
consumed by `2_cross_deconv/step2_deconv.py` and `head_to_head_bootstrap/`
are regenerated by `2_cross_deconv/step1_extract.R` and are not shipped.

These analyses read the same frozen two-gene model as the main pipeline
(intercept 1.85981, PDK2 -1.76987, PDK4 -2.43690; see
`pipeline/frozen/final_model_coefficients.csv` (shipped archive; regenerated at `results/frozen/` by step 8)).
